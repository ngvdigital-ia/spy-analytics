Estabilidade conta em quantos dias a oferta se manteve em escala. Um dia conta como “em escala” quando a contagem fica dentro da tolerância abaixo do maior nível que a oferta já alcançou — dia que sobe sempre conta. Peso maior para a sequência de dias em escala que chega até hoje sem quebra.

Sincronização da equipe

É isto que faz o painel ser um só para todo mundo. Ligado, tudo o que qualquer pessoa registrar — ofertas, leituras, correções, pesos — aparece para os outros em poucos segundos, em qualquer navegador ou computador. Duas pessoas podem trabalhar ao mesmo tempo: as alterações se juntam por registro, ninguém sobrescreve o trabalho do outro.

A sala rápida é gratuita e não pede cadastro, mas o servidor descarta salas que passem 24 h sem ninguém abrir — e quem tiver o código enxerga os dados. Serve para a equipe já trabalhar junto hoje. Para guardar de forma definitiva e privada, troque para Supabase: a mudança leva 2 minutos e leva todo o histórico junto.
Como preparar o Supabase em 2 minutos
  1. Crie uma conta em supabase.com e um projeto novo (o plano gratuito basta).
  2. Abra SQL Editor, cole o bloco abaixo e execute.
  3. Em Project Settings › API, copie a Project URL e a chave anon public para os campos acima e clique em Conectar.
  4. Use Copiar convite e mande o link para a equipe: quem abrir já entra configurado.
create table if not exists spy_analytics (
  id            text primary key,
  dados         jsonb not null,
  atualizado_em timestamptz default now()
);

alter table spy_analytics enable row level security;

create policy "equipe le"     on spy_analytics for select using (true);
create policy "equipe cria"   on spy_analytics for insert with check (true);
create policy "equipe altera" on spy_analytics for update using (true) with check (true);

Estas políticas liberam leitura e escrita para quem tiver a chave anon — é o mesmo nível de confiança de compartilhar o link do painel. Se precisar restringir de verdade, coloque o Supabase atrás de login e troque as condições true por auth.role() = 'authenticated'.

Qualquer endereço que responda GET devolvendo o JSON guardado e aceite PUT gravando o JSON recebido — e que libere CORS para o domínio do painel. O arquivo servidor/worker.js do repositório é um Cloudflare Worker pronto para isso.

Corrigir leituras

Errou uma contagem ou registrou no dia errado? Escolha a oferta, altere o número direto na lista ou remova a leitura. Tudo recalcula na hora.

Como a nota é lida

Acima de 75 a oferta está sustentando escala com volume e tempo suficientes para bancar uma tradução. Entre 60 e 75 é candidata forte, normalmente falta tempo de acompanhamento. Entre 45 e 60 vale seguir observando. Abaixo de 45 a oferta tentou escalar e recuou. Ofertas com menos de 4 leituras aparecem marcadas como pouco dado — a nota existe, mas ainda não decide nada.

Na faixa de leituras do painel, o traço vermelho embaixo marca os dias em que a oferta saiu de escala. Emenda de traços vermelhos no fim da faixa é oferta caindo agora.

Com a sincronização ligada, as ofertas e as leituras são as mesmas para todo mundo: quem registrar de qualquer navegador ou computador alimenta o mesmo painel. Cada máquina guarda uma cópia, então dá para trabalhar sem internet — ao reconectar, as duas pontas se juntam. O estado aparece no canto superior direito e se ajusta em Dados e critérios · Sincronização da equipe.
